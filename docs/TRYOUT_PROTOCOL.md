# Voluntary study protocol / 自愿试学流程

Open `#/about/tryout` on either edition. The Chinese and English page provides three independently selectable tasks: derivatives, the fundamental theorem, and washers. Each task connects reading, an existing experiment, and a transfer problem with changed conditions.

1. Choose an unfamiliar topic; record whether this is first learning or review only if the participant wishes to include it in free text. No identity is required.
2. Before operating the model, predict what will change and why. Perform the stated operations, including the counterexample where available.
3. Explain the observation without opening its reference explanation. Then compare reasons and mathematical conditions; do not treat agreement of a few graph points as proof.
4. Attempt the transfer problem without hints. If stuck, use a hint and mark that assistance explicitly. Inspect the solution only after the attempt.
5. Return to the study page, choose the actual outcome and write the point where understanding changed or remained unclear. Download the notes before leaving. The participant decides whether to share them through GitHub; no automatic submission occurs.

评价要看能否在换情境后独立说明原因，而不只看是否完成按钮操作。保留未看提示、看提示后完成、看解答后仍不清楚与未尝试的区别。记录原先想法、改变判断的具体一步和未解决的问题；不收集姓名、联系方式或浏览器记录。

反馈属于待核实材料。核对具体教材位置、条件、推导和题解后，再提出改动。单个案例可以发现困惑，不能证明整体教学效果；没有参与者结果时，明确记录为“流程已准备，试学尚未开展”。本次没有招募、冒充或生成读者。
