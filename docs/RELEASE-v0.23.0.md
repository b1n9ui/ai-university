# v0.23.0 · Misconception feedback and transfer practice

The first complete volume receiving authored misconception feedback is Calculus I v0.3.4: all 35 lessons, 70 incorrect-option explanations in each language, and 35 reflection questions with reference explanations. These are fixed authored responses, not an automated diagnosis of the reader's reasoning. Correct responses continue to show the canonical explanation.

Where an existing diagram actually illustrates the relevant relationship, feedback opens its authored preset. Some conceptual checks concern different functions from the available diagram; these retain a general lesson-diagram link rather than pretending it reproduces the exact counterexample. Textual counterexamples cover cases such as product differentiation and inverse-trigonometric branches.

All mathematics diagrams gain optional temporary prediction notes. The 35 Calculus I walkthroughs also pair the reader's prediction with a final explanation task and reference answer. Notes are held only in component memory, not uploaded or saved as learning records. They are not automatically graded. Freely modified parameters remain explicitly separate from fixed preset observations.

Six new transfer exercises change the original setting: a changed point value, a cubic difference quotient, a decreasing inner function, a moving squared integration bound, a shifted rotation axis, and a forbidden application of l'Hopital. The volume now contains 197 exercises including review and assessment. Walkthrough completion links directly to its selected exercise using a stable question ID.

Both sites include a voluntary self-guided study page at `#/about/tryout`, linked from the reading guide. It offers three tasks, explicit outcome reporting, local Markdown export, and an optional GitHub feedback link. It does not send notes automatically or attach browser history or learning records. No reader trial outcomes have been collected or claimed in this change.

Canonical JSON, fixed English source snapshots and checksums, full-book Markdown, printable HTML, independent lesson HTML/Markdown and machine-readable content indexes remain aligned. Shared prediction-note support reaches all 345 mathematics lessons; authored option feedback and reflection coverage is 35/345, not all eight books.

Validation evidence and mathematical checks: see [misconception QA](audits/2026-10-27-misconceptions/README.md). This release does not establish measured learning effectiveness or exhaustive mathematical correctness.
