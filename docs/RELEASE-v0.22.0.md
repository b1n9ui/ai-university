AI University v0.22.0 improves the learning flow across all 345 mathematics lessons in the separate Chinese and English editions.

- Contextual help offers another explanation, incremental derivations, guided worked examples, and direct links to actual prerequisites. All responses come from the fixed textbook content; there is no live chat, generated answer, model API or visitor tracking.
- Wrong concept choices keep the correct option hidden until the reader asks for the answer. Readers can retry, inspect the authored explanation, or continue into the diagram. Keyboard retry returns focus to the choice.
- Worked examples support one step at a time, going back, revealing the whole solution, and trying again. Definitions, conditions, complete answers and static manuscript exports remain available.
- Guided diagrams gain an explicit start, current step, graph focus, nearby observation checkpoints, original-preset warnings, and a final route into exercises. On wide desktop screens the task stays beside the model; narrow screens retain a single reading order.
- Exercise feedback avoids irrelevant generic unit warnings; an individual question's self-assessment record can be cleared without touching other questions. Three-dimensional coordinate labels are larger and clearer.

The canonical textbook versions and mathematical models are unchanged. The two programming textbooks retain their existing execution-replay interfaces. This release is a bounded UX improvement, not a claim that every lesson has been manually reviewed or that learning effectiveness has been measured.
