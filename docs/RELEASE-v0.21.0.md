AI University v0.21.0 makes the complete textbooks easier to find, read, cite, and improve.

- 766 complete static lesson pages and Markdown counterparts across the separate English and Chinese editions. Definitions, conditions, derivations, examples, exercise answers, sources, and links to actual interactive diagrams come from the existing fixed textbook content.
- Stable lesson URLs, visible citation/version information, matching structured metadata, content fingerprints, learning/prerequisite index, optional llms.txt guides, and sitemaps with 794 HTML URLs. Search indexing and AI citation are not guaranteed.
- Contextual feedback entrances in mathematics and programming lessons. A voluntary form carries the lesson/edition/version into a public GitHub draft; readers review and submit themselves. No local learning history is sent.
- A new textbook submission template, owner-controlled review queues, and a read-only GitHub workflow that groups public feedback into evidence packets. Reader claims stay unverified; no feedback automatically rewrites, approves, merges, or publishes a textbook.

The website remains static and requires no runtime model API or account for reading. AI maintenance runs outside the website; static export and feedback collection are not model training. Official admission remains with the project owner. Original textbook content versions are unchanged; the pending C contribution is excluded.
