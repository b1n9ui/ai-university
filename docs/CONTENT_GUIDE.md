# 教材内容规范

## 写作方式

第一句话说明知识点解决什么问题。先用可检验的直觉给读者抓手，再给精确定义与条件。术语出现时解释用途，不用复杂词汇替代解释；也不把必需的数学条件当作可删掉的“壁垒”。

每节增加一个三选一概念检查（含条件反馈）和一个演示预测问题。例题可先尝试，再展开解法；独立练习仍提供提示与完整解答。

每节至少包含三个正文段落、三个推导步骤、两个逐步例题、两个误区和四道带完整答案的练习。不是列一张公式表就算完成。例题包含基础与迁移；练习按识别、计算、应用与条件检查逐渐展开。

## Learning object 字段

| 字段 | 用途 |
|---|---|
| concept / intuition | 核心意思与直觉 |
| learningCheck | 针对具体误区的提问、三个选项、正确索引与解释 |
| body / objectives | 系统正文与学习目标 |
| formalDefinition | 定义或定理、LaTeX、全部适用条件 |
| derivation | 分步解释为何成立，不只展示结果 |
| interactiveVisual | 对应模式、数学模型、预测问题与观察任务 |
| workedExamples | 题目、逐步计算、答案与必要单位 |
| commonMistakes | 错误想法与具体纠正 |
| practice | 题目、提示、答案、完整解法与难度 |
| prerequisites | 本卷已出现或已出版前卷的前置概念 ID；跨卷链接保留明确所属书 |
| difficulty | 1–6 的相对认知负担，非标准化成绩 |
| misconceptionTags | 与本节具体误区连接的标签 |
| provenance / sources | AI 生成状态、版本、是否人工审校及来源 |

## 数学排版

正文、题干、选项、反馈、标题、图示说明、解题步骤和附录中的数学表达必须使用 `$...$`；独立公式使用 `$$...$$` 或 `latex` 字段。分数使用 `\frac{...}{...}`，根号使用 `\sqrt{...}`，上下标使用 `^{...}` / `_{...}`，函数名使用 `\sin` / `\ln` 等命令。不要直接输入 `1/√(x−2)`、`x²`、`x ≥ 2` 等普通字符代替公式排版。

变量采用数学斜体，单位采用 `\mathrm{cm}` 等正体。`numericAnswer` 保持数值类型；公式标记不用于 ID、路径、模型选择键或数值计算。网页与打印版共用公式分段规则，禁止在浏览器中猜测文本后自动改写数学意思。百分号写作 `\%`，不要让 TeX 注释符把答案后半段隐藏。

`npm run validate:content` 会检查未标记的符号、损坏的公式分隔符与无效 TeX。发布前还要观察实际桌面和手机页面：公式基线、根号覆盖范围、分数分子分母、长公式滚动与选择题布局均需确认。程序检查不能替代数学语义核对。

## 数学表达

- 区分函数值、有限极限与无穷趋势；0/0 不当作数值。
- 导数、原函数与换元明确所讨论区间。反函数注明分支；对数与根式注明定义域。
- 定理附连续、可导与闭区间等条件。零导数只是极值候选，二阶零点只是拐点候选。
- 区分近似与等式、带符号积分与面积、位移与路程、旋转侧面与含端盖总面积。
- 练习答案可由原问题复算；符号答案建议通过求导、代回或第二种解法确认。
- `numericAnswer` 只用于明确的标量题，误差容许约为 1e-5；不把表达式字符串匹配伪装成数学自动评分。

## 来源与版权

本书的正文与图重新编写。参考课程可用于确定范围和核对条件；不要复制受限教材段落、截图与题库。公开引用具体来源与用途。AI 生成不免除来源与许可证记录的责任。

## 教学设计资料

见 [本轮资料研究与落实](LEARNING_RESEARCH.md)。来源支持一种设计方向，不自动证明本书有效。图示要同时回答“改变什么量、观察什么结果、为什么成立”；3D 只用于空间关系，保留二维视图、键盘操作与无 WebGL 时的回退。

练习难度按题目的实际认知负担标注，不按题号机械递增；误区标签只连接该题确实检验的误区，不相关时使用空数组。章末与综合题的提示应指出具体切入口，避免所有题共用一句提示。

## 回答式教学模块

每节 `teaching.explain` 用另一种简短说法回应核心问题，不重复原段落。`teaching.steps` 固定三步，每步给出标题、操作指令、受控参数 `preset` 与该预设下的观察。每卷的模型与正文须对应，不能给线性方程配非线性方程并冒充同一示例。参数必须映射到真实控件、在合法范围内；观察文字不能暗示有限采样构成证明。自由操作后需明确标注原预设观察，不能把固定文字冒充实时分析。

网页、搜索和打印版使用同一份教学文字。验证会拒绝无效实验参数。新题的提示优先指出入口与条件；不能仅凭数值匹配就声称读者理解了概念。

## 误区反馈与迁移任务

`learningCheck.responses` 可按三个选项分别提供 `text` 与 `experimentStep`（零起始的实验索引；无对应实验为 `null`）。错误项解释须回应这个选项的具体错误；不能把通用讲解复制三遍，也不能声称诊断了读者的思维。仅在现有模型真实支持时连接预设，不得把其他函数的图示冒充题目本身。

`teaching.reflection` 提供观察后的 `question` 与 `answer`。问题应要求解释变化、适用条件或采样的限制；参考解释是固定内容，不是对读者自由文字的自动分析。`teaching.transferExerciseId` 指向本节真实练习，优先选择改变函数、条件、方向或情境后仍须应用同一原理的题。必须保留完整提示与题解。

新增内容同步至固定英文源、整本书稿、打印版与单节导出。读者预测和解释只在页面暂存，不上传；真实试学采用 [自愿流程](TRYOUT_PROTOCOL.md)，不得把自动检查或 AI 自测当成人类试学结果。

## 中文文案规则

- 直接写概念、问题或操作。删除“先带着一个问题”“改变一个量，看清一个关系”等不提供信息的提示。
- 按钮说明点了会发生什么，例如“查看说明”“恢复本步参数”。保持阅读指南与实际按钮名称一致。
- 同一操作只说明一次。问题、步骤和结果已经写清时，不再加一段泛泛的学习建议。
- 演示说明须对应当前模型；例如改变非均匀密度时，不能把问题写成整块板同比例变重。
