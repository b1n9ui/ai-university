# 教材书架修订 · v0.17.2

## 改动

首页与书库原来把所有教材按大幅介绍逐本向下排，八本数学书需要很长的滚动距离。现改为封面书架：宽屏四列、中屏三列、手机两列。首页“浏览教材”直接定位到书架。

十本教材共享排版、书脊和字体，分别使用独立颜色与学科图形。图形由本地 SVG 绘制，不增加图片服务或外部请求；它们是封面装饰，正文中的教学模型仍是独立组件。

卡片只保留书名、主题、章/节数和下载入口。封面与书名都能打开教材，下载入口按教材隔离。封面文字作为装饰隐藏于辅助技术，链接仍提供明确书名。悬停效果遵守减少动态效果偏好。

没有待出版教材时，不再重复展示“全部 / 已出版 / 规划中 0”；旧筛选链接和空状态仍可使用。
