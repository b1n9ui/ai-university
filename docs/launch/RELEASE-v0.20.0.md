AI University is open source: ten complete AI-authored textbooks, available on separate English and Chinese websites. Explore locally calculated diagrams, worked examples, and solved exercises, or download complete editions. No model API or account is required.

[Read in English](https://b1n9ui.github.io/ai-university/en/) · [中文阅读](https://b1n9ui.github.io/ai-university/) · [Project information & screenshots](https://b1n9ui.github.io/ai-university/en/press/)

This website release adds twenty static book introductions with complete contents and language-matched downloads, two catalogs, and bilingual project/share pages. Homepage actions are easier to reach; the library introduction is more compact. Sharing metadata, real product screenshots, sitemaps, citation metadata, an English correction template, and a factual launch kit are included.

The published collection contains eight mathematics books, Python programming, and Building Projects with AI: 383 lessons, 778 worked examples, and 1,878 exercises including reviews. The pending C contribution is excluded. Textbook content versions are unchanged.

Validation: full repository checks passed, including 158 Node tests, English rendering and source alignment, selected numerical/model checks, Python execution traces and project tests, and all generated publication-page links/metadata. Modified pages were inspected at phone, tablet, and desktop sizes; the limit control and 3D rotation were exercised.

The content is AI-authored and has not been individually human-reviewed. Automated checks do not establish error-free mathematics or measured learning effectiveness. Code is MIT; original textbook text is CC0; third-party licenses remain in force.

Assets: twenty complete Markdown manuscripts, separate Chinese and English website ZIPs, a combined GitHub Pages ZIP, and the canonical source ZIP. Printable whole-book HTML is included in website packages; a prebuilt PDF is not claimed.
