## What to show

1. [Limits](https://b1n9ui.github.io/ai-university/en/#/lesson/limit-intuition?view=visual): change the approach and compare the function value with its limit.
2. [Vectors in 3D](https://b1n9ui.github.io/ai-university/en/#/lesson/c3-vectors?view=visual): rotate the view and inspect vector addition.
3. [Python execution](https://b1n9ui.github.io/ai-university/en/#/book/python-introduction/names-types/experiment): step through fixed program traces and inspect variable values.

Choose a topic you know; read the explanation and conditions, operate the visual, then check an exercise solution. Send concrete corrections through [Issues](https://github.com/b1n9ui/ai-university/issues/new/choose) or a pull request.

## Publication boundaries

AI writes and revises the textbooks offline. The website delivers fixed editions; it has no runtime chatbot, model API, accounts, or learning-data server. Local learning records stay in the browser. Site hosting still serves normal network requests.

The release includes eight mathematics books, Python, and Building Projects with AI. The C contribution is pending and is excluded. Original textbook text is CC0; code is MIT; third-party licenses remain in force. Books are downloadable as Markdown and printable HTML; browser printing can produce a PDF. No prebuilt PDF, formal accreditation, educator endorsement, measured learning benefit, or exhaustive human/math verification is claimed.

## First launch

Publish the protected, checked GitHub release and matching sites first. Use the repository and project pages as durable announcement material. Community posts require a chosen destination/account and a fresh rules check; publication there is not part of the completed website release. Do not send mass unsolicited messages, request votes, or present AI-written prose as human writing.

Each release binds source, static sites, and twenty manuscripts to one canonical commit. See [release process](../RELEASING.md). Stable book introduction URLs and sitemaps aid discovery; they do not guarantee indexing or search rank.
