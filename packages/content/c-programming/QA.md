## 项目覆盖明细

正常样例的独立手算：88+59+100=247，人数 3，平均显示 82.33，及格人数 2；排序 Ada 100、Lin 88、Bo 59。

- 空文件、标准 LF、CRLF、最后无换行、同分按名字、合法 0 / 100、前导零。
- 空行、缺字段、多空格、尾空格、正负号、101 分、非数字后缀、制表符、非字母姓名、超过 20 字符姓名。
- 超出行缓冲、long 范围溢出文本、内嵌 NUL、裸 CR、多余 CR、前两行正确而第三行非法。
- 重复姓名拒绝，100 人总分 10000 正确，第 101 人拒绝。
- 参数不足/过多、文件不存在；错误输入 stdout 为空且 stderr 非空、状态非零。
- 插入失败保留原长度与记录；解析失败不改输出 Student；加载失败保留调用前目标，成功才转移临时表所有权。

## 语义自检与明确局限

规则按 WG14 N1570 的相关章节核对：数组与指针转换、整数除法、scanf 范围要求、无符号移位、字符串终止、malloc/realloc 所有权、标准流错误返回。它是 C11 草案，书中标明仅核对与 C17 共通基础，没有冒称 C17 正式规范。

- 课堂 scanf 案例严格限于目标类型可表示的小整数；读取成功个数不能验证任意范围数字。项目全部使用有界文本读取与完整解析。
- 指针非空不等于有效；不执行悬空、越界、重复释放等错误片段来宣称固定输出。
- 项目仅处理常见 ASCII 兼容执行环境的英文字母姓名，不支持 Unicode 名称、区域排序或任意字符集。
- 普通测试没有强制模拟系统分配器耗尽、设备级读写/关闭失败或标准输出设备故障；这些分支做了代码检查，不能写作已覆盖所有资源失败。Sanitizer 不证明未执行路径和所有泄漏都不存在。
- 项目报告不提供原子文件保存或并发更新。shell 输出重定向会先截断目标，文档明确禁止重定向到输入文件或任何别名。
- 网页预测是固定程序对比，不是通用 C 执行器、逐行跟踪器或代码自动评分服务。
- 未完成真实零基础读者可用性研究，未全平台运行、未逐页 PDF 审核，未声称人类审校或无误保证。
