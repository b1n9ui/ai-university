# C 语言：从零到完整程序

完整中文 v0.1.0 教材，面向没有编程或终端经验的读者。先解释文件、目录、编辑器、编译器、保存、编译和运行，再进入语言本身。基线为 C17 常用子集，工具为 GCC / Clang；不把 C17 称作最新标准。

本分支提供完整书库接入；提交 PR 不等于已合并或部署到线上。

## 事实来源与检查

`book.json` 是顺序、边界、来源与版本；`lessons/*.json` 是正文和题解唯一来源；`supplements.json` 是回顾、综合题、术语和附录；`project/` 是项目唯一源码。不要直接修改派生书稿或输出包。

```sh
npm run build:c
npm run check:c
npm run check
```

需要 Node.js 22.12+、Python 3.9+ 和支持 C17 的 GCC/Clang。现有 Python 教材的轨迹复核另有 CPython 版本要求，见仓库 README。`CC=clang npm run check:c` 可显式选择编译器。支持的环境可另跑：

```sh
C_SANITIZE=1 npm run check:c
```

- `tools/validate.mjs` + schema：登记、章节编号、完整字段、来源、误区、练习与更早先修 DAG。
- `tools/verify.py`：以 C17、常用警告及 `-Werror` 编译 116 个固定案例，逐一比较 stdout、stderr 和退出状态；每个案例在独立临时目录运行。
- 同一工具编译真实项目和单元检查，外部测试覆盖空文件、LF/CRLF、无末换行、同分、零/百分、坏格式、超长、内嵌零、重复、100/101 人、错误参数及失败保留原目标。
- `tools/build.mjs`：生成完整 Markdown；调用 `bundle.py` 生成固定文件顺序与时间戳的源码 ZIP。`--check` 拒绝过期产物。
- 主构建从同一内容生成可搜索条目和打印 HTML；`npm run check` 已包含 C 检查，远端 CI 也会执行。

工具只执行本仓库已查看的固定代码；临时目录与超时不是未知代码安全沙箱。平台、浏览器证据与未测路径见 [QA.md](QA.md)。

## 项目独立运行

下载 ZIP 后进入 `project/`，照其 README 构建：

```sh
gcc -std=c17 -Wall -Wextra -Wpedantic main.c records.c input.c -o gradebook
./gradebook sample.txt
```

macOS 可用 clang；Windows 使用 MSYS2 UCRT64，运行 `./gradebook.exe sample.txt`。预期人数 3、总分 247、平均 82.33、及格 2，再输出 Ada 100 / Lin 88 / Bo 59。

项目最多 100 人，姓名 1..20 个 ASCII 英文字母，单空格分隔成绩。整份文件验证成功才生成报告，加载失败保留调用前目标；不静默丢弃坏行。重定向输出不可指向输入文件或其别名，避免 shell 预先截断输入。
