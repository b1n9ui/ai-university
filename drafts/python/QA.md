## 独立核对的关键行为

- 装糖果：全部 105 种数量/袋容量组合，用重复减去袋容量的独立算法核对袋数和余数。覆盖 0 颗、少于一袋、刚好装完及有剩余。
- 行号时序：箭头指向下一行执行前的状态；赋值后才更新变量，print 后才增加输出。
- 分支：4 元时跳过“可以乘车”，执行“钱不够”。
- 循环：倒计时条件依次检查 3、2、1、0；起点 0 时不执行循环体。range 的空区间和终点不包含另有答案片段核对。
- 函数：调用时进入局部参数 number，return 后回到 result；参数不显示为全局变量。
- 列表：历史步骤的值保存为当时文本，后续 append 不会倒改之前的观察状态。
- 文件：每次执行从独立临时工作目录开始，中文读写与空文件结果一致。
- 金额项目：手算 1250+300+800=2350 分，餐饮 2050 分、交通 300 分；精确展示、大整数、坏表头/列数/金额、文件错误、无半份报表、导入无输出与 CLI 退出行为由原有 15 项测试核对。项目每条记录要求正整数分，0 与负数拒绝；合法空表总计 0。
