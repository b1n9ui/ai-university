# 新学科投稿：带着 AI 做项目

这是一份完整的 v0.1.0 教材草稿，面向会用 AI 写代码、但缺少项目开发整体认识的人。目标是让读者能自己确定目标、选择范围、理解关键路径、判断结果，再让 AI 协助实现。遵循 CONTRIBUTING.md：先给完整课程边界，独立放在 drafts 中，不混入正式数学卷。

| 章 | 三节主线 | 学完留下什么 |
| --- | --- | --- |
| 1 先想清楚 | 用户场景、首版范围、验收 | 一页项目计划和三类案例 |
| 2 看懂项目 | 文件职责、数据路径、运行环境 | 文件图、数据图、实际运行记录 |
| 3 Git | 三种状态、协作、恢复与冲突 | 小步提交、分享方式与恢复判断 |
| 4 Agent 协作 | 真实上下文、任务卡、审阅 | 可执行任务与可核对证据 |
| 5 可靠性 | 测试、排错、数据与权限 | 边界检查、复现材料、操作边界 |
| 6 交付 | 存储设计、发布、综合实作 | 可运行项目、说明、版本与限制 |

18 节、36 个逐步例题、72 道带完整解答的练习、18 个概念检查、54 个逐步情境判断、12 道章末回顾、4 道综合题、32 个术语，以及同版完整项目。每节至少三段解释、三步操作、两个误区，并连接更早的先修节点。主线不要求已有语言、Git 或终端基础；第一次运行、版本检查、文件保存和目录操作从头解释。语法学习仍需继续，本书不替代完整编程课程。

以个人“学习清单”贯穿全部章节，避免只背术语：添加、完成、删除、同源浏览器保存、JSON 备份与确认恢复。实现使用原生 HTML/CSS/JS；Node 本地静态服务器与内置测试，无第三方依赖、模型后端、账号或云服务。复杂多人业务、支付、生产认证、高级 Git 历史改写不在本卷范围，没有空白后续章节。

## 网页与教学交互

仓库 Node.js 22.12+ 环境中：

```sh
npm ci
npm run dev
```

打开 http://127.0.0.1:5173/#/ai-development 。它是独立的延迟加载投稿预览，未注册为正式数学卷。阅读、互动、练习分开；另有项目、回顾、术语与整本下载。手机目录可展开、导航后关闭，并可用 Escape 收起。阅读标记仅本机存储，不能当作自动掌握评估。

- 每节情境题：三个连续决定，各选项均有解释；答对才继续，可重练。自由文字练习只供读者对照，不自动评分。
- Git 台：工作区、暂存区、HEAD 三列，两类 diff、分支顶端与模拟远端一起变化。可观察暂存后再编辑、普通提交、取消暂存、恢复、分支、推送及撤销普通提交。它是单文件教学模型，按钮不操作真实仓库；不模拟网络、认证、冲突、未跟踪文件或高级历史；切分支要求干净状态，真实 Git 有时可携带改动。正文单独解释这些限制。
- 任务卡台：目标、事实、范围、验收、验证、交付六栏生成可复制文本，示例来自 canonical JSON。只提示空栏目，不做关键词评分，不声称填满就正确，不调用 AI。输入不跨页或刷新保存。
- 项目页：同版数据图、四关卡、完整源码与 ZIP。先写自己的计划再看参考；ZIP 解压后可独立运行。

来源采用 Git、GitHub、MDN、npm、Node、Anthropic 与 OWASP 官方文档，逐节注明用途。提示词六栏、关卡与情境是原创教学设计，来源不能证明学习效果或保证模型表现。正文未复制第三方段落、截图或题库。

## 文件与构建

- book.json：课程、边界、版本、来源、许可。
- lessons/*.json：18 节的唯一事实来源，含情境与任务卡模板。
- supplements.json：回顾、实作、术语及项目关卡。
- learning-object.schema.json：独立开发教材结构；不填数学公式冒充现有数学 schema。
- lib/git-lab.mjs：网页纯状态模型；类型声明在同目录。
- project/：完整项目唯一源码；其中 README 也是 ZIP 的运行说明。
- tools/validate.mjs：schema、登记、先修顺序、来源与题目完整性。
- tools/git-lab.test.mjs：真实临时 Git 仓库逐步对照，而非只测试模型调用自身。
- tools/build.mjs：生成整本 Markdown、网页源码包、确定性的项目 ZIP。
- AI-Assisted-Development.md、project.generated.json、learning-list.zip：同版派生产物，不手改。
- QA.md：实际验证与限制；PR_DESCRIPTION.md：未来提交说明。

```sh
npm run build:ai-development
npm run check:ai-development
npm run check
```

check:ai-development 校验课程，运行 8 项 Git 检查和 13 项项目规则测试，并检查书稿、源码包与 ZIP 是否过期。原有 check 保持原职责，包括网站类型检查、生产构建和 24 项原有测试；远端 CI 不自动运行新教材检查，审阅时需另跑。生成产物随内容一起提交。测试只在一次性临时目录中操作 Git；不是运行未知第三方代码的安全沙箱。

独立运行项目（无需 npm install）：

```sh
npm test --prefix drafts/ai-development/project
npm start --prefix drafts/ai-development/project
```

访问 http://127.0.0.1:5180 。更适合读者的方式是从网页下载 ZIP，在解压目录按其 README 执行 npm test 与 npm start。
